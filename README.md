# Flappy Bird

## Описание
Простая реализация популярной игры на языке Python с использованием библиотеки Tkinter. Цель игры — управлять птичкой, которая летит через препятствия, избегая столкновений. Постарайтесь пройти как можно дальше и набрать максимальное количество очков!

## Как играть?
- Кликните мышкой по области окна чтобы запустить/перезапустить игру.
- Используйте пробел для управления птичкой.
